# Magent

[English](README.md) | 中文

Magent 是一个完全使用 Swift 编写的网络代理项目，为 macOS、iOS 和 Linux
提供轻量、快速且安全的网络代理软件。不同平台共享同一套可移植的网络核心，并支持多端同步。

## 项目

### [Magent](Magent/)

Magent 是各平台共用的底层通用代理类库。

### [MagentX](MagentX/)

MagentX 是基于 Magent 类库构建的原生 macOS 应用。

### [iMagent](iMagent/)

iMagent 是基于 Magent 类库构建的原生 iOS 应用。
