# Security Review Scope

This repository is owned and maintained by MarlinL.

Security analysis is authorized for this repository and its local
development/test environments.

The purpose of security review is defensive:

- identify vulnerabilities
- determine root causes
- validate findings in the local test environment
- propose fixes
- verify that fixes eliminate the vulnerabilities

Do not target third-party systems, production systems, or infrastructure
outside this repository's controlled test environment.
