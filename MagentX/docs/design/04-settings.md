# 系统设置（Settings）

## 页面定位

管理应用的全局配置项，包括启动行为、本地代理端口等系统级参数。

## 功能模块

### 常规设置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 开机自动启动 | Toggle | OFF | 系统登录时自动启动应用（Launch at Login） |
| 静默启动 | Toggle | OFF | 启动时隐藏主窗口，仅在菜单栏显示 |
| SOCKS5 本地端口 | TextField (数字) | 1080 | SOCKS5 代理监听端口 |
| HTTP 本地端口 | TextField (数字) | 61086 | HTTP 代理监听端口 |
| 当前版本号 | 只读文字 | v1.0.0 | 显示当前应用版本 |

### 配置说明

#### 开机自动启动 (Launch at Login)

- 控制应用是否注册为 macOS Login Item
- 开启后系统登录时自动启动 MagentX
- 适用于长期后台代理场景

#### 静默启动

- 开启后应用启动时不显示主窗口
- 用户可通过菜单栏或 Dock 图标手动呼出
- 与「开机自动启动」配合使用实现无感代理

#### 本地端口

| 端口 | 协议 | 默认值 | 说明 |
|------|------|--------|------|
| SOCKS5 端口 | SOCKS5 (RFC 1928) | 1080 | 标准 SOCKS5 代理端口，支持 SOCKS5 完整四阶段协议 |
| HTTP 端口 | HTTP Proxy | 61086 | 支持 CONNECT 隧道（HTTPS）和 Forward 代理（HTTP） |

- 端口修改实时保存
- 如果代理服务正在运行，需重启服务才能生效
- Dashboard 页面中也可以修改端口（两个页面共享同一数据源）

## 数据模型

```swift
struct AppSettings {
    var launchAtLogin: Bool   // 开机自动启动
    var silentLaunch: Bool    // 静默启动
    var socksAddress: String  // SOCKS5 监听地址（默认 "127.0.0.1"）
    var socksPort: Int        // SOCKS5 监听端口（默认 1080）
    var httpAddress: String   // HTTP 监听地址（默认 "127.0.0.1"）
    var httpPort: Int         // HTTP 监听端口（默认 61086）
}
```

## 数据持久化

- 设置作为 `AppState.settings` 的一部分，通过 `UserDefaults` 以 JSON 格式持久化
- 使用自定义 `init(from decoder:)` 实现向后兼容：新增字段（如 `socksAddress`、`httpAddress`）使用 `decodeIfPresent` 并提供默认值
- 所有设置变更通过 `@Published` 属性的 `didSet` 自动触发持久化
