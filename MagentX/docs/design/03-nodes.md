# 网络节点（Nodes）

## 页面定位

管理 Shadowsocks 代理服务器节点。用户在此添加、编辑、选择、测速和删除代理节点配置。

## 功能模块

### 1. 服务器列表

以 `Table` 组件展示所有节点：

| 列名 | 宽度 | 说明 |
|------|------|------|
| 节点别名 | ≥150pt | 当前选中节点前显示青色 ✓ 图标 |
| 地址 (Server) | ≥160pt | 等宽字体显示服务器地址 |
| 端口 | 60pt | 服务器端口 |
| 加密方式 | 180pt | `caption` 字体显示完整加密方法名 |
| 延迟 | 80pt | 测速结果（绿色圆点 + `Nms`）/ "未测速" |
| 操作 | 260pt | 一组操作按钮 |

#### 操作按钮

| 按钮 | 说明 |
|------|------|
| 选择 | 设为当前活跃节点，已选中时按钮禁用 |
| 修改 | 弹出编辑 Sheet，预填当前配置 |
| 测速 | 通过该节点发起 TCP 连通性测试，计算往返延迟 |
| 删除 | 从列表中移除该节点（红色垃圾桶图标） |

### 2. 节点编辑 Sheet

以 Modal Sheet 形式弹出，支持「增加」和「修改」两种模式：

| 字段 | 类型 | 校验 |
|------|------|------|
| 节点别名 | TextField | 不能为空 |
| 服务器地址 | TextField | 不能为空 |
| 端口 | TextField | 必须可转为 `UInt16` |
| 加密方式 | Picker 下拉 | 枚举所有 `CipherMethod` |
| 密码 | SecureField | 不能为空 |

**支持的加密方式（CipherMethod）：**

- `aes-128-gcm`
- `aes-256-gcm`
- `chacha20-ietf-poly1305`
- `xchacha20-ietf-poly1305`

**交互逻辑：**

1. 保存按钮在所有字段合法时才可用
2. 新增模式：`id` 自动生成，端口默认 `19999`，加密方式默认 `chacha20-ietf-poly1305`
3. 修改模式：预填已有节点数据，保存时覆盖原记录
4. 保存后关闭 Sheet，列表即时更新

### 3. 节点测速

**测速流程：**

1. 通过 `ShadowsocksProxy` 建立到该节点的 SS 隧道
2. 发送 HTTP HEAD 请求到 `www.gstatic.com:80`（`/generate_204`）
3. 使用 `ContinuousClock` 计算从请求发出到响应接收的耗时
4. 成功：更新节点延迟（毫秒整数）
5. 失败（超时 5 秒、连接失败、解密错误）：清除延迟值，显示"未测速"

**UI 反馈：**

- 测速完成前无 loading 状态（异步执行）
- 测速完成后表格行自动刷新延迟列

## 数据模型

```swift
struct ProxyNode {
    var id: UUID          // 唯一标识
    var name: String      // 节点别名
    var address: String   // 服务器地址（IP 或域名）
    var port: UInt16      // 服务器端口
    var method: String    // 加密方式 rawValue
    var password: String  // SS 密码
    var latency: Int?     // 延迟（毫秒），nil = 未测速
}
```

## 数据持久化

- 所有节点保存在 `AppState.nodes` 数组中
- 当前选中节点 ID 保存在 `AppState.selectedNodeId`
- 删除选中节点时自动切换到列表第一个节点
- 通过 `UserDefaults` 以 JSON 格式持久化
