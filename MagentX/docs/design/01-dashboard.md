# Dashboard（仪表盘）

## 页面定位

应用的主入口和全局监控中心。用户在此查看当前代理运行状态、网络配置概要、实时流量，以及快速启停本地代理服务。

## 页面布局

```
┌─────────────────────────────────────────────────────────────────┐
│ Dashboard                                                       │
│                                                                 │
│  ┌──────────────────────────┐  ┌──────────────────────────────┐│
│  │ 网络配置状态              │  │ 本地服务                      ││
│  │                          │  │                              ││
│  │ 当前节点  HK-01 (AEAD)   │  │ SOCKS5 代理         [ON/OFF] ││
│  │ 服务器地址 1.2.3.4:19999 │  │ 地址 [127.0.0.1] 端口 [1080] ││

│  │ 状态  ● 运行中           │  │ 地址 [127.0.0.1] 端口 [61086]││
```

采用左右两栏布局：

- **左栏**（自适应宽度）：状态卡片 + 流量卡片，纵向排列
- **右栏**（固定 320pt）：本地服务卡片

## 功能模块

### 1. 网络配置状态卡片

| 字段 | 说明 |
|------|------|
| 当前节点 | 显示选中节点名称及加密方式（如 `HK-01 (chacha20-ietf-poly1305)`） |
| 服务器地址 | 远端 SS 服务器 `<IP>:<Port>` |
| 本地 SOCKS5 | 本地 SOCKS5 代理监听地址 |
| 本地 HTTP | 本地 HTTP 代理监听地址 |
| 状态 | 运行中（绿色圆点 + 文字）/ 已停止（灰色文字） |

- 未配置节点时显示"未配置节点"占位文案

### 2. 实时流量卡片

- 24 根柱状条，每 0.6 秒刷新，展示代理运行时的流量波动
- 代理停止时柱状图静止
- 底部显示实时上/下行速率文字（如 `↓ 12.3 KB/s`、`↑ 5.1 KB/s`）

### 3. 本地服务卡片

SOCKS5 和 HTTP 代理服务各自独立控制：

| 控件 | 说明 |
|------|------|
| 启停开关 | Toggle 切换服务的运行/停止状态 |
| 地址输入框 | 监听地址，默认 `127.0.0.1` |
| 端口输入框 | 监听端口，SOCKS5 默认 `1080`，HTTP 默认 `61086` |

**交互逻辑：**

1. 打开开关时，读取当前选中节点配置，启动对应代理服务
2. 若无选中节点，开关操作无效
3. 地址/端口修改实时保存到 `AppSettings`，下次启动时生效
4. SOCKS5 和 HTTP 服务完全独立，可分别启停

## 前置依赖

- 必须在「网络节点」中配置并选中至少一个 SS 节点
- SOCKS5 代理使用 `Socks5Server`（完整 RFC 1928 + RFC 1929 四阶段协议）
- HTTP 代理使用 `HttpProxyServer`（支持 CONNECT 隧道和 Forward 代理）
