# 001 Dashboard Page Design

## Context

Dashboard 是 MagentX 的首页，面向每天打开应用后只想确认“代理是否可用”的用户。它需要把当前节点、本地代理端口、运行状态和流量反馈集中在一个页面，减少用户在节点、策略、设置之间来回切换。

## Core Logic

页面加载后先读取当前选中的节点和本地代理配置，再根据 `ProxyManager` 展示 SOCKS5、HTTP 的运行状态。用户可以在页面内启动单个服务，也可以一键启动或停止全部服务。启动服务时必须使用当前节点和对应监听地址、端口。流量区只表达服务是否有活动，不承担详细日志功能。

## Contract

- 输入：当前节点、SOCKS5 地址与端口、HTTP 地址与端口、服务运行状态、上下行速度。
- 输出：启动 SOCKS5、启动 HTTP、停止单个服务、停止全部服务、复制端点。
- 状态：未选择节点、已停止、启动中、运行中、启动失败。
- 视觉约定：运行状态用颜色和短文本表达；地址、端口、服务器信息使用等宽字体；主操作按钮始终可见。

## Corners

- 未选择节点时，启动按钮禁用，并展示明确空状态。
- 地址为空或端口非法时，不启动服务，并显示失败信息。
- 启动失败后，开关回到关闭状态，保留错误文本。
- 长服务器地址和端点必须截断，不挤压布局。
- 停止全部服务时，SOCKS5 和 HTTP 状态都要同步归零。
