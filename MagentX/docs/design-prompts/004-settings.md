# 004 Settings Page Design

## Context

Settings 页面用于维护 MagentX 的低频配置，包括启动偏好、本地监听地址和端口。用户通常只在首次配置或端口冲突时进入该页面。

## Core Logic

页面按配置类型分组：常规设置、本地代理设置、关于信息。常规设置直接写入应用状态。本地代理设置修改 SOCKS5 和 HTTP 的监听地址、端口，供 Dashboard 下次启动服务时读取。Settings 不直接启动或停止代理，避免配置行为和运行行为混在一起。

## Contract

- 输入：启动偏好、SOCKS5 地址与端口、HTTP 地址与端口、版本号。
- 输出：更新启动偏好、更新监听地址、更新监听端口。
- 状态约定：设置变更即时保存；服务是否运行由 Dashboard 控制。
- 输入约定：地址为文本；端口为数字输入并配合 Stepper；端口范围为 1-65535。
- 视觉约定：分组清晰、控件密度适中，不使用大面积说明文案。

## Corners

- 端口输入小于 1 时自动修正为 1。
- 端口输入大于 65535 时自动修正为 65535。
- 地址为空时允许保存，但 Dashboard 启动时必须拦截并提示。
- 用户修改运行中服务的端口时，不自动重启服务。
- 版本信息只读，不提供编辑入口。
