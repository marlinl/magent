# 002 Node Page Design

## Context

Node 页面用于管理 Shadowsocks 节点，是 MagentX 能否代理成功的前置配置页。目标用户需要快速添加服务器、选择当前节点、检查延迟，并在配置错误时能立即修正。

## Core Logic

页面以节点表格为中心，展示所有可用节点。新增节点后自动保存并设为当前节点。选择节点会更新全局当前节点，后续 Dashboard 启动服务时使用该节点。编辑节点只修改配置，不改变节点身份。测速通过当前节点发起连通性请求，并把结果写回该节点的延迟字段。

## Contract

- 输入：节点列表、当前节点 ID、节点延迟、测速状态。
- 输出：新增节点、编辑节点、选择当前节点、删除节点、测试延迟。
- 节点字段：别名、服务器地址、端口、加密方式、密码、延迟。
- 表单约定：别名、地址、密码不能为空；端口必须是 1-65535；加密方式只能来自支持列表。
- 表格约定：当前节点必须有明确标记；操作按钮使用图标并提供 hover 说明。

## Corners

- 节点列表为空时，展示空状态和新增入口。
- 删除当前节点前必须确认，并停止正在运行的代理服务。
- 删除后如果还有节点，应自动选择下一个可用节点。
- 测速期间按钮禁用，避免重复请求。
- 测速失败时延迟显示为未测速，不把错误堆栈暴露给用户。
- 编辑节点时保留原节点 ID 和已有延迟。
