# Magent

English | [中文](README_zh.md)

Magent is a pure Swift network proxy project for macOS, iOS, and Linux. It
provides lightweight, fast, and secure proxy software with multi-device
synchronization, while sharing one portable networking core across platforms.

## Projects

### [Magent](Magent/)

Magent is the low-level, general-purpose proxy library shared across platforms.

### [MagentX](MagentX/)

MagentX is the native macOS app built on the Magent library.

### [iMagent](iMagent/)

iMagent is the native iOS app built on the Magent library.
